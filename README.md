mend applies an edit that an AI model wrote to a tree of text files. It reads all four formats models write — unified diffs (even with wrong line numbers), SEARCH/REPLACE blocks, V4A patches and JSON tool calls — finds the lines each edit names even when their whitespace has drifted, and changes every file or none.

## Run it

```sh
node main.ts [--format=NAME] [--check] [--strict] [PATCH]
```
